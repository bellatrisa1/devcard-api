## Фактически выполнено

- `npm run build`, `npm run lint`, `npm run prisma:validate`: успешно.
- `npm test`: 3 HTTP/конфигурационных теста прошли, включая GraphQL production, health, validation/null/error sanitization.
- `npm run test:database` с TEST_DATABASE_URL на отдельный PostgreSQL 17: 2 интеграционных теста прошли. Каждый создаёт/удаляет только собственную случайно названную БД; developer database не сбрасывается.
- Повторно измерено 6 SQL statements с исходными данными и с дополнительными 20 работами/200 достижениями. Проверены полный и точный запросы, корректные достижения, стабильный порядок и отсутствующий профиль при наличии постороннего.
- В отдельной временной копии выполнен `npm ci --omit=dev --offline`: установка успешна, audit — 0 уязвимостей. Отсутствие tsc-watch не мешает production startup.
- На новой acceptance-БД проверены migrate deploy → seed → bootstrap. Повторный startup production-копии оставил 1 профиль, 27 навыков, 27 связей, 2 работы, 7 достижений и 3 проекта; применена одна миграция.
- Ошибка миграции при недоступной БД и реальный конфликт seed: startup завершился с кодом 1 до запуска HTTP, без вывода connection credentials. Проверка выполнялась только на acceptance-БД; временный конфликт восстановлен.
- Реальная потеря тестовой БД: ready 200 → 503 → 200 после восстановления; live остаётся 200.
- SIGTERM production-процесса: процесс завершился без SIGKILL, число его PostgreSQL-соединений уменьшилось с 1 до 0. Runtime logs не содержали неожиданных ошибок или connection strings.

## Браузер

Использованы уже установленные Playwright 1.63 и Chromium, без добавления browser-зависимостей в проект. Открыт production endpoint `/graphql`, загружены встроенный Sandbox и документация схемы. Точный многострочный запрос работодателя введён в Monaco editor и выполнен кнопкой Run. Получен JSON без errors, ответ отобразился в UI: Белла Манкиева, 27 навыков, Буше → МКБ, Orbit → Lexora → Event Form Flow App.

В процессе исправлен стартовый пример Apollo: вместо несуществующего root id предлагается рабочий запрос к profile. Браузерная проверка выполнена против production-only копии с этим изменением. Скриншот локальной сессии: `/private/tmp/devcard-step4-sandbox-success.png` (временный артефакт, не часть репозитория).

Первоначальная попытка кликнуть служебный textarea Monaco завершилась timeout: он скрыт по устройству редактора. Повторная проверка через видимую область редактора и кнопку Run прошла. Это ошибка способа автоматизации, не сбой API. Страница также загружает внешние сервисы Apollo; их доступность в другом браузере/сети нужно проверить отдельно.

Проверка production-only копии на macOS подтверждает состав зависимостей, но не заменяет Linux image execution.

Реальные Render networking/TLS, health routing и публичный URL не проверялись, ресурсов не создавалось.
